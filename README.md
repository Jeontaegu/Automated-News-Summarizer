# 📰 AI 네이버 뉴스 3줄 요약 & 이메일 발송 봇 (Powered by Gemini)

특정 키워드의 최신 네이버 뉴스를 자동으로 검색하고, Google Gemini AI를 통해 핵심만 3줄로 요약하여 지정된 이메일로 전송해 주는 자동화 파이썬 스크립트입니다.

## 1. 어떤 문제를 해결하려 했는지 🤔

* **정보 과부하 및 시간 부족 해결:** 매일 쏟아지는 수많은 뉴스 기사 중 관심 있는 주제(예: 부동산, 주식 등)의 기사를 일일이 찾아 읽는 것은 많은 시간이 소모됩니다. 이 프로그램은 기사 본문을 읽지 않아도 핵심 내용만 빠르게 파악할 수 있도록 돕습니다.
* **관심 키워드 모니터링 자동화:** 특정 키워드에 대한 최신 동향을 파악하기 위해 매번 포털 사이트에 접속해 검색하는 번거로움을 없앴습니다.
* **효율적인 정보 전달:** 브라우저를 열어 검색 결과를 확인하는 대신, 매일 사용하는 이메일로 정제된 요약본을 직접 배달받아 업무 효율성 및 정보 접근성을 높이고자 했습니다.

## 2. 어떤 기능을 구현했는지 🛠️

* **네이버 뉴스 API 기반 맞춤형 검색:**
* 사용자가 지정한 키워드(기본값: "부동산")와 관련된 최신 기사 목록을 네이버 OpenAPI를 통해 정확도(sim) 순으로 가져옵니다.


* **웹 스크래핑을 통한 기사 본문 자동 추출:**
* `BeautifulSoup`과 `requests` 라이브러리를 활용하여, 네이버 뉴스 자체 링크(`n.news.naver.com`)에 해당하는 기사 페이지에 접속한 뒤 본문 텍스트만 깔끔하게 스크래핑합니다.


* **Google Gemini AI 3줄 요약:**
* 최신 LLM인 `gemini-3.5-flash` 모델을 사용하여, 길고 복잡한 기사 본문을 단 **3줄**로 빠르고 정확하게 요약합니다.


* **자동 이메일 발송 (SMTP):**
* 추출 및 요약된 결과물을 하나로 취합하여, 사용자가 입력한 수신자 이메일로 즉시 발송합니다.
* 보안 강화를 위해 `getpass` 모듈을 사용하여 이메일 발송용 비밀번호 입력 시 화면에 노출되지 않도록 처리했습니다.
* 메일 제목에 발송 당시의 한국 시간(KST)과 검색 키워드를 자동으로 포함하여 정리하기 쉽게 만들었습니다.

## 3. 사전 준비 사항 (Prerequisites)

이 프로그램을 실행하기 위해서는 아래의 API 키 및 설정이 필요합니다.

1. **네이버 개발자 센터 API 키:**
* `NAVER_CLIENT_ID` 및 `NAVER_CLIENT_SECRET` 발급 (검색 API)


2. **Google Gemini API 키:**
* Google AI Studio에서 발급받은 `GEMINI_API_KEY`


3. **발송용 Gmail 계정 및 앱 비밀번호:**
* Google 계정 설정 -> 보안 -> 2단계 인증 활성화 -> **앱 비밀번호** 생성 (16자리)



## 4. 실행 방법 (How to Run)

1. 코드 상단의 API 키 변수 부분에 발급받은 키를 입력합니다.
```python
NAVER_CLIENT_ID = "본인의_네이버_클라이언트_ID"
NAVER_CLIENT_SECRET = "본인의_네이버_시크릿_키"
GEMINI_API_KEY = "본인의_제미나이_API_키"

```


2. 필요한 라이브러리를 설치합니다.
```bash
pip install requests beautifulsoup4 google-generativeai

```


3. 스크립트를 실행하면 콘솔에서 이메일 전송을 위한 정보를 묻습니다.
* **보내는 사람의 Gmail 주소:** 본인의 이메일 주소 입력
* **Gmail 앱 비밀번호:** 16자리 앱 비밀번호 입력 (입력 시 화면에 보이지 않음)
* **받는 사람의 이메일 주소:** 요약본을 받아볼 이메일 주소 입력



## 5. 라이브러리 및 스택

* **Language:** Python
* **Web Scraping:** `requests`, `BeautifulSoup` (`bs4`)
* **AI API:** `google.generativeai` (Gemini 3.5 Flash)
* **Email:** `smtplib`, `email.mime`
* **Others:** `urllib`, `json`, `re`, `getpass`, `datetime`, `zoneinfo`
